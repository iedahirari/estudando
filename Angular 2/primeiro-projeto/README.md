# PrimeiroProjeto

This project uses Angular 22 and the Angular application builder. The existing NgModule and study components are preserved.

## Requirements and setup

Use Node.js 22.22.3+, 24.15.0+, or 26+ within the ranges declared in `package.json`, and npm 8.3+.

From this directory, run `npm ci` to install the locked dependencies. Run `npm audit` to check dependency security.

## Development server

Run `npm start` for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## Code scaffolding

Run `npx ng generate component component-name` to generate a new component. You can also use `npx ng generate directive|pipe|service|class|guard|interface|enum|module`.

## Build

Run `npm run build` to build the project. The build artifacts will be stored in `dist/primeiro-projeto/`.

## Running unit tests

Run `npm test` to execute the unit tests via [Karma](https://karma-runner.github.io).

For a single headless run, use `npm test -- --watch=false --browsers=ChromeHeadless`. Chrome must be installed; set `CHROME_BIN` if it is not detected automatically.

## Running end-to-end tests

No end-to-end test runner is configured.

## Further help

To get more help on the Angular CLI use `npx ng help` or check the [Angular CLI documentation](https://angular.dev/tools/cli).
